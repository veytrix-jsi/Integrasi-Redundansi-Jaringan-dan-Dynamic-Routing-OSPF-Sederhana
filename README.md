# Integrasi-Redundansi-Jaringan-dan-Dynamic-Routing-OSPF-Sederhana
Merancang jaringan tahan gangguan dengan menggabungkan jalur cadangan (redundansi) dan dynamic routing OSPF Single-Area. Menggunakan metrik Cost untuk menentukan rute utama dan melakukan failover otomatis saat jalur terputus, sehingga meminimalkan downtime tanpa konfigurasi ulang manual.
